# 更新日志 / Changelog

## 2.0.0 — 2026-10-14

这是整理后的首次公开成品发布，包含此前在家中使用的备份功能。以下是当前版本功能和本次发布准备内容。

- Windows 原生窗口；扫描基岩旧商店版、新版 GDK、Preview / Beta 和 Java 默认存档目录。
- 手动多世界 ZIP 备份；恢复工具 ZIP、普通世界 ZIP 及 `.mcworld`，同名目录另存。
- 游戏退出或设定小时数后自动检查，每世界保留最新一份；无变化不重写，内容校验后替换。
- 托盘、单实例及当前用户登录自启；程序、窗口、托盘、快捷方式和按钮使用统一图标。
- 发布准备：完整双语安装/使用/恢复说明、MIT 与第三方许可声明、统一版本文件、EXE 版本资源、便携包和 SHA-256。
- 当前限制：中文界面，Windows x64 成品；Java 默认路径；不转换游戏版本/版本类型；自动备份每世界仅一个最新版本。

This is the first organized public binary release, including the backup features previously used at home. The following describes the current version and preparation for this release.

- Native Windows UI; detection for older Store Bedrock, newer GDK, Preview / Beta, and default Java saves.
- Manual multi-world ZIP backup; tool ZIP, ordinary world ZIP, and `.mcworld` restoration with duplicate directories preserved.
- Automatic checks after game exit or at a configured hourly interval; one latest archive per world, unchanged archives preserved, content checked before replacement.
- Tray operation, single-instance activation, sign-in startup, and matching application/window/tray/shortcut/action icons.
- Release preparation: complete bilingual setup/use/restore guides, MIT and third-party notices, one version file, EXE version resources, a portable package, and SHA-256 checksums.
- Current limits: Chinese UI, Windows x64 binary, default Java location, no edition/version conversion, and one latest automatic archive per world.

更早的家庭使用没有正式版本日志，因此不补写未记录的历史版本。 / Earlier family use had no formal version log; undocumented historical releases are not reconstructed.
